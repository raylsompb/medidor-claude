# Challenges 2026-11-19

- O terminal do VS Code/Claude Code exporta `ELECTRON_RUN_AS_NODE=1`. Com ele, `electron .` roda como Node e `app` vem `undefined`; o instalador também herda e o app não abre. Rodar com `env -u ELECTRON_RUN_AS_NODE` ou `Remove-Item Env:ELECTRON_RUN_AS_NODE`.
- npm 11.20 não executou o postinstall do pacote `electron` (sem `dist/`). Rodar `node node_modules/electron/install.js` (scripts/install-electron.ps1).
- `capturePage` logo após `showInactive` devolve frame velho (segmentos sem cor). Chamar `webContents.invalidate()` e esperar ~300 ms antes de capturar.
- Login: o app não consegue usar a sessão do navegador principal. Fonte principal virou o login do Claude Code (`~/.claude/.credentials.json`, endpoint `api.anthropic.com/api/oauth/usage`), só leitura, sem renovar token. Login pelo navegador = `claude auth login`. QR code não serve: loga o celular, não o PC.
